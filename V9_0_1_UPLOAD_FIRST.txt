LATIN REVISION V9.0.1 — EMBEDDED ARTWORK HOTFIX

Why this release exists
-----------------------
The UI artwork is embedded directly inside index.html as WebP data URIs.
Therefore GitHub Pages no longer needs assets/*.png paths for the app artwork.
This removes the broken-image problem caused by missing/mis-cased asset uploads.

Service worker
--------------
Install cache now depends only on the five core files.
Artwork is already inside index.html.

Upload these files to GitHub root
---------------------------------
index.html
app.js
question-bank.js
sw.js
manifest.webmanifest

Keep your existing icons/ folder.
You do NOT need to upload assets/ for V9.0.1.

After deploy
------------
1. Wait for GitHub Pages Action to finish.
2. Open the site in Safari and refresh.
3. Fully close the Home Screen PWA.
4. Reopen it.
5. The artwork should load even if assets/ is absent.
