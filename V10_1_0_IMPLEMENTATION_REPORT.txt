- Builds/repairs forms from source-covered components

4. SENTENCE MOSAIC
- Builds Latin production items from the teacher-covered sentence bank
- Scaffolding reduces as levels rise
- Validation is token/structure based rather than one exact visual slot order
- Does not teach a single compulsory English-like Latin word order
- Distractors only appear at later levels and are derived from unlocked material

5. VERBUM MATCH 2.0
- Six levels change cognitive demand, not merely board size/lives
- Recognition, reverse recall, source-covered form-family connection, sorting and grammar relationships
- Clues are derived from teacher/source metadata rather than generic invented Latin rules
- Uses learned/unlocked source material only

6. MANUSCRIPT MYSTERY
- Progressive single-case flow:
  Restore → Inspect → Connect → Sequence → Interpret → Case Solved
- One stage active at a time
- Evidence/tool tray changes with the current stage
- Uses teacher-covered set-text / translation / grammar / comprehension sources
- No one-click reveal-all shortcut

7. CONTENT GATING
- questionUnlocked() checks the dated teacher plan
- already-started/completed source cycles and prior attempts may also make already-seen material eligible
- all game selectors draw from unlockedBank()
- no second independent syllabus was created

8. FLEXIBLE LATIN ANSWER VALIDATION
- Production games use canonicalised token/structure checks where appropriate
- Sentence Mosaic does not compare only one raw full-string order
- Required lexical/morphological material remains source-locked
- No runtime invention of additional acceptable Latin forms

9. REPAIR / ECHO SYSTEM
- First wrong: combo reset + targeted clue + repair opportunity
- Correct repair: reduced points
- Second wrong: answer + Must Remember, weakness recorded
- Skill retest scheduled after roughly 3–5 interactions
- Short Echo Round revisits tricky skills without rewriting formal mastery

10. PERSISTENCE
